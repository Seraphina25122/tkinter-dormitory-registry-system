# 宿舍离楼回楼登记管理系统

基于 Python Tkinter 开发的宿舍离楼回楼登记管理系统，面向宿管人员使用。

## 功能特点

- **学生离楼登记**：记录学生离楼信息（楼栋、姓名、寝室号、床位号、离楼日期）
- **学生回楼登记**：记录学生回楼信息，支持多选操作
- **未回楼学生查询**：一键查询未回楼学生，支持排序、搜索、多选联系辅导员
- **修改已有记录**：修改或删除已有登记记录
- **批量导入数据**：支持 CSV 和 Excel(.xlsx) 格式批量导入
- **智能助手**：实时统计数据、风险预警、决策辅助
- **数据自动备份**：启动时自动备份，保留最近10个备份文件
- **审计日志**：记录登录、增删改查、数据导出等操作
- **楼栋管理**：支持4栋楼（1号楼、2号楼、3号楼、4号楼）数据分类管理

## 环境要求

- 操作系统：Windows 7/10/11
- Python 版本：Python 3.6 及以上

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行程序

```bash
python main.py
```

或直接双击 `main.py` 文件运行。

## 使用说明

1. **离楼登记**：点击"学生离楼登记"，填写学生信息和离楼日期，系统会自动校验数据
2. **回楼登记**：点击"学生回楼登记"，选择学生后填写回楼日期
3. **未回楼查询**：点击"未回楼学生查询"，查看当前楼栋未回楼学生名单
4. **修改记录**：点击"修改已有记录"，修改或删除已有记录
5. **导入数据**：点击"导入新数据"，选择 `测试导入数据` 文件夹中的文件即可体验批量导入
6. **查看全部学生**：点击"查看全部学生名单"，查看所选楼栋全部学生

## 数据格式

CSV 文件字段顺序：
```
楼栋,姓名,寝室号,床位号,离楼日期,回楼日期,备注
```

## 注意事项

- 回楼日期必须大于等于离楼日期
- 批量导入时重复记录（楼栋+姓名+寝室号+床位号+离楼日期完全一致）会自动跳过
- 程序启动时会自动备份数据到 `data/backups/` 目录
- 审计日志记录在 `audit_log.txt` 文件中（运行时自动生成）
- 示例数据中的学生姓名均为虚构
